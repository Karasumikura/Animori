## 关于 Animori

Animori 是一款面向画质爱好者的 Flutter 番剧播放应用。在自定义规则与多视频源的基础上，加入跨源码率实测、自动优选播放，以及 Liquid Clarity 界面，减少反复切换片源的操作。

## 为画面而选

- **跨源自动优选**：检索已配置规则中的番剧来源，探测视频流，自动选择成功测量来源中码率最高的一项。
- **实测码率与画面尺寸**：通过视频流采样获取码率，并在可解析时识别分辨率，帮助判断片源质量。
- **来源排行榜**：展示探测结果，支持自动播放推荐来源，也支持手动选择。
- **记住优选结果**：缓存来源排名，再次观看时更快进入播放。
- **实时超分辨率**：支持 Anime4K，为低分辨率片源提供额外的画面增强选项。

自动优选基于可访问、成功解析并完成测量的片源。当前排名以实测码率为依据；码率并不是画质的唯一指标，最终观感也取决于分辨率、编码方式与片源本身。
